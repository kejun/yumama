# KEJ-23：宇妈的厨房实现方案

需求：[KEJ-23](https://linear.app/kejunz/issue/KEJ-23/创建一个静态站)  
仓库：<https://github.com/kejun/yumama>

## 目标与范围

将 issue 评论中的 3 篇菜谱转换为可独立访问的静态页面。所有菜谱图片保存在仓库，页面不依赖下厨房接口或图片热链。手机做饭场景优先，桌面与打印仍可使用。

| 103730028 | 红烧带鱼 | 7 步 | 封面 + 10 张步骤图 |
| 104361302 | 香煎厚切牛排 | 8 步 | 封面 + 21 张步骤图 |

食材数量沿用原作。做法用本站语言归纳为操作步骤，合并重复动作，保留 `sourceSteps` 映射和完整步骤图片集。保留原作标题、作者、链接、收录日期；不复制广告、评论和长篇个人经历。原作未给出的用量标明“原作未注明”，不猜测。牛排的安全中心温度单独引用 FoodSafety.gov，不把原作低熟度示例当成安全标准。

## 信息与视觉设计

首页提供菜谱目录、食材/菜名搜索、分类和本机收藏。详情页按准备食材、做法步骤、厨房笔记排列。页面采用米白底、深绿色操作按钮、陶土色提示、宋体标题及真实菜品图片。

手机使用单列卡片，食材勾选区和步骤图保持足够字号。底部保留进入烹饪模式的按钮，兼容安全区域。桌面使用双列详情与三列目录；打印时去除交互按钮，保留食材、步骤与来源。

## 技术方案

- Node.js 22+ 的构建脚本读取 `data/recipes.json`，生成首页、每道菜的独立 HTML 与 404 页。
- 浏览器运行原生 CSS / ES modules，不依赖 UI 框架、服务端、数据库、模型或登录。
- 图片与静态脚本用相对路径，支持域名根目录或 GitHub Pages 的 `/yumama/` 子路径。
- `public/` 为共享样式、交互代码和图片；`dist/` 为可部署产物，不提交到 Git。
- `data/image-sources.json` 记录 44 张图片的来源、尺寸、字节数和 SHA-256；本地图片压缩后约 4.6 MB。
- 每页内嵌 JSON；HTML 在未启用 JavaScript 时仍包含全部正文。无客户端数据请求。
- 搜索与收藏完全在浏览器执行，详情页无需等待客户端渲染。

## 厨房交互

1. 勾选食材并记住本机勾选状态；一键清空。
2. 全屏烹饪 dialog 逐步显示图片、动作和关键时间。大字切换，上一/下一步，随时展开食材用量。
3. 关闭模式或刷新后记住进度；做完后可开始新一轮。不同菜谱的状态隔离。
4. 对原作明确给出的时长提供计时按钮；支持暂停、继续、取消、重新计时。每道菜一个计时器，替换运行中的计时需要用户在页面确认。
5. 计时以绝对截止时间计算，页面进入后台不会产生累计计时偏差；恢复页面时校准。锁屏/离开页面不承诺声音或通知提醒，界面明确说明。
6. Screen Wake Lock 由用户手动开启。不可用或失败时给出实际状态；退出烹饪后释放，回到可见页面时尝试恢复。
7. 本地存储禁用、损坏或空间不足时退化为当前会话使用，并提示不能持久保存。存储内容按类型、范围校验。

## 验收与交付

- 构建校验所有图片存在、路径合法、菜谱 slug 唯一。
- 测试搜索筛选、收藏、食材勾选、步骤进度、恢复、异常存储、计时暂停/恢复/到期、常亮释放与失败。
- 校验生成页面中所有本地链接、图片与锚点可解析，图片 SHA-256 与清单一致，无远程运行资源。
- GitHub CI 执行 `npm ci`、`npm run check`，归档 `dist/`。
- 提供手动触发的 GitHub Pages 部署工作流，选择仓库 Pages / GitHub Actions 后可发布。
- 实际浏览器视觉、iOS 锁屏与常亮行为需在真实浏览器/手机上验证。本轮环境没有 Sites 规定的浏览器验证入口，不将 DOM 测试称为真机或浏览器验证。

## 后续收录

新增来源后先核对标题、作者、食材、步骤与图片，再将整理后的内容写入 `data/recipes.json`，下载图片并记录清单，运行构建与检查。原网站需要验证码或内容无法核实时，停止导入该项并说明缺失内容，不生成替代菜谱。本站不提供面向任意 URL 的自动爬取接口。

## 本轮验证结果

`npm run check` 通过：语法检查、7 组自动化测试、静态构建。覆盖 3 个菜谱页、44 张本地图片的完整性、全部本地资源与页面锚点、搜索收藏、进度恢复、计时状态、异常存储和常亮请求的失败/退出竞态。

交互测试运行于 linkedom DOM 环境；没有执行真实浏览器排版、焦点行为、移动端滚动、打印版式或 iOS 真机常亮测试。这些是本轮剩余验证边界。
